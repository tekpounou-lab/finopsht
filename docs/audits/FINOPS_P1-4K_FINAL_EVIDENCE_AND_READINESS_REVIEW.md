## 4. Gate C — Cryptographic Payroll Integrity (`integritySeal`)

### Payload Field Coverage Matrix
The cryptographic SHA-256 integrity seal (`integritySeal`) generated by `PayrollCalculationEngine.ts` covers:

| Field Category | Included Property | Verification Impact |
|---|---|---|
| **Identity & Scope** | `businessId`, `employeeId`, `periodKey` | Prevents cross-tenant or cross-employee hash spoofing |
| **Financial Amounts** | `grossPay`, `finalPayout` | Any mutation in gross salary or net payout invalidates hash |
| **Run-Level Audit Seal** | `recordCount`, `totalGrossHTG`, `totalNetHTG` | Protects entire run sheet against record deletion or insertion |

### Cycle Immutability Enforcement
Cycles in protected statuses (`SEALED`, `LOCKED`, `VALIDATED`, `PAID`) cannot be overwritten or recalculated. `PayrollService.ts` explicitly checks cycle status and throws `CycleImmutabilityViolation` before any database mutation occurs.
